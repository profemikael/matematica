Como resolver uma equação do 2º grau

FORMA GERALax² + bx + c = 0
DISCRIMINANTEΔ = b² − 4·a·c
BHASKARAx = (−b ± √Δ) ÷ 2a
O QUE Δ INDICAΔ>0: duas raízes
Δ=0: uma raiz
Δ<0: nenhuma

1º) Identifique a, b e c — atenção aos sinais negativos. 2º) Calcule o Δ. 3º) Aplique Bhaskara: o símbolo ± significa fazer DUAS contas, uma somando e outra subtraindo a raiz de Δ. Em problemas de medidas (terrenos, salas), a raiz negativa é descartada: comprimento não pode ser negativo.

Exemplo 1 — Resolva x² − 5x + 6 = 0.
a = 1, b = −5, c = 6.   Δ = (−5)² − 4·1·6 = 25 − 24 = 1.
x = (5 ± √1) ÷ 2 = (5 ± 1) ÷ 2  →  x₁ = 3  e  x₂ = 2.

Exemplo 2 (incompleta) — Resolva x² − 49 = 0.
Isole o x²: x² = 49 → x = ±7. As raízes são 7 e −7.
Como responder: digite apenas os NÚMEROS (sem a unidade). Use vírgula ou ponto para decimais — os dois funcionam. Quando a questão tiver mais de um campo, só passa para a próxima quando TODOS estiverem corretos.
