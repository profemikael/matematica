A parábola: zeros e vértice

FUNÇÃOy = ax² + bx + c
DISCRIMINANTEΔ = b² − 4ac
VÉRTICE (x)xv = −b ÷ 2a
VÉRTICE (y)yv = −Δ ÷ 4a

O gráfico da função quadrática é uma parábola. Se a > 0 ela abre para cima e o vértice é o ponto de mínimo; se a < 0 abre para baixo e o vértice é o ponto de máximo. Os zeros da função são os pontos em que a parábola cruza o eixo x, encontrados por Bhaskara. Em problemas de maior lucro, maior área ou altura máxima, a resposta está sempre no vértice.

Exemplo resolvido — Encontre o vértice de y = x² − 4x + 3.
a = 1, b = −4, c = 3.   xv = 4 ÷ 2 = 2.
Δ = 16 − 12 = 4  →  yv = −4 ÷ 4 = −1.   Vértice: (2, −1), ponto de mínimo.
Como responder: digite apenas os NÚMEROS (sem a unidade). Use vírgula ou ponto para decimais — os dois funcionam. Quando a questão tiver mais de um campo, só passa para a próxima quando TODOS estiverem corretos.
