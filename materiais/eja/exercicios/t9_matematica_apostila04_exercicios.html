MARGEM DE ERROresultado ± margem

Uma pesquisa ouve só uma parte das pessoas, a amostra, para tirar conclusões sobre o todo, a população. Se a amostra é representativa, a mesma porcentagem vale para a população. Desconfie de gráficos com o eixo cortado: eles fazem diferenças pequenas parecerem enormes. Em pesquisa eleitoral, o resultado real está num intervalo: resultado menos a margem até resultado mais a margem. Se os intervalos de dois candidatos se encostam ou se cruzam, é empate técnico.

Exemplo resolvido: Candidato A com 45% e Candidato B com 50%, margem de erro de 3 pontos.
1º) A: de 45 − 3 = 42% até 45 + 3 = 48%.
2º) B: de 50 − 3 = 47% até 50 + 3 = 53%.
3º) Os intervalos se cruzam entre 47% e 48%: é empate técnico. Dizer que B "está na frente" força a conclusão.
Como responder: digite apenas os NÚMEROS (sem a unidade). Use vírgula ou ponto para decimais, os dois funcionam. Quando a questão tiver mais de um campo, só passa para a próxima quando TODOS estiverem corretos.
